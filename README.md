# fitlover_mvps

	•	Benutzerprofil & Login (Google, Apple, E-Mail)
	•	Eigene Workout-Erstellung
	•	Vorgefertigte Trainingspläne (Anfänger, Fortgeschrittene, Profis)
	•	Offline-Speicherung mit SQLite
	•	Nutzung der ExerciseDB API
	•	Dunkles Design mit hellblauen Akzenten

FitLover – Dein smarter Fitness-Coach
Mit FitLover erstellst du eigene Workouts, wählst aus professionell erstellten Trainingsplänen und speicherst deine Fortschritte ganz ohne Internetverbindung. Dank Login mit Google, Apple oder E-Mail und deinem persönlichen Profil startest du flexibel und sicher. Entdecke über 1.300 Übungen per ExerciseDB API und trainiere stilvoll im Dark Mode mit hellblauen Highlights. Ob Anfänger oder Profi – FitLover bringt Struktur in dein Training.
